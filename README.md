# 千页 · Qianye

**一窗千页，各有所归。**

千页是一款面向 Windows 的多标签文件管理器，基于 [Tablacus Explorer](https://github.com/tablacus/TablacusExplorer) 定制。把常用文件夹收进同一个窗口，用标签切换工作位置，用两组独立收藏整理常用目录。

## 下载与安装

前往本仓库的 **Releases** 页面，下载安装程序 `Qianye-Setup-1.0.0-Win10-Win11-x64.exe`。

- 面向 Windows 10 1809 及以上、Windows 11，Intel/AMD 64 位电脑。
- 默认只为当前用户安装，不要求以管理员身份运行。
- 如果缺少 Microsoft Edge WebView2 Runtime，安装向导会调用微软官方引导程序，需要联网。
- 安装时可选择接管普通文件夹/磁盘打开，以及 Win+E；两项默认不勾选。
- 项目尚未购买代码签名证书，Windows 可能显示“未知发布者”。

## 主要功能

- **多标签浏览**：等宽标签，图标与名称一起居中，分隔线清晰，关闭按钮仅在悬停时出现。
- **两组独立收藏**：顶部和左侧分别管理；拖入文件夹添加，按住 Ctrl 拖动排序。
- **自定义启动位置**：右上角齿轮可将当前文件夹设为默认，也能浏览选择或输入路径；直接启动和 Win+E 共用设置。
- **清晰的文件列表**：整行蓝色选择、浅灰隔行底色，默认显示名称、修改日期、大小、类型、创建日期。
- **紧凑列宽与排序**：名称获得主要空间，默认修改日期从新到旧；文件大小自动使用 MB、GB 等单位。
- **路径和磁盘空间**：底部显示当前路径、所在磁盘及可用空间；“此电脑”保留磁盘容量视图。
- **快速再次打开**：关闭窗口时清空标签，程序在后台保留；下次只打开请求的位置。
- **Windows 窗口习惯**：右上角最小化、最大化、关闭，直角窗口。

## 日常操作

| 操作 | 方法 |
| --- | --- |
| 增加收藏 | 将文件夹拖到顶部或左侧收藏区 |
| 调整收藏顺序 | 按住 Ctrl 拖动收藏项目 |
| 修改默认打开位置 | 右上角齿轮 → 设为当前文件夹 / 选择文件夹 / 手动输入路径 |
| 恢复默认启动位置 | 右上角齿轮 → 恢复为“此电脑” |
| 新建文件夹 | 点击“新建文件夹”，随后直接重命名 |
| 彻底退出后台 | 托盘图标右键 → 彻底退出，或按 Shift 关闭窗口 |

双击指定文件夹会打开该文件夹，默认启动设置不会覆盖明确指定的位置。初始收藏使用接收者电脑自己的桌面、下载和文档，不包含开发时的个人目录、历史或缓存。

## 卸载和升级

在 Windows“设置 → 应用”中卸载“千页文件管理器”。卸载只停止本安装目录中的进程；若文件夹关联和 Win+E 启动项仍归本安装所有，会恢复之前的设置。用户之后改用其他软件的设置不会覆盖。

个人收藏和配置会保留，便于再次安装。收藏只是目录入口，卸载不会删除这些目录里的真实文件。升级时运行新安装程序即可。

## 从源码构建

需要 Windows x64、Node.js 18+、.NET Framework 4.x 自带的 C# 编译器，以及 [Inno Setup 6.4.3](https://github.com/jrsoftware/issrc/releases/tag/is-6_4_3)。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1 -IsccPath "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

脚本会先检查发布目录中是否混入个人路径和使用记录，再编译辅助程序、下载并验证微软 WebView2 引导程序签名，最后在 `dist/` 生成安装包和 SHA-256 校验文件。

`app/` 包含经过清理的上游运行文件和定制源码；`installer/` 是安装与卸载脚本；`tools/` 是构建和发布检查脚本。`app/config/` 只保留四份初始模板，用户的实际设置不应提交到仓库。
